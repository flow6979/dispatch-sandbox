# Security Policy

We take the security of this project seriously and appreciate your help in
keeping it safe.

## Supported Versions

Security updates are provided for the latest release only. Please make sure
you are running the most recent version before reporting an issue.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub
issues, pull requests, or discussions.

Instead, report them privately using GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
feature (**Security → Report a vulnerability** on this repository).

When reporting, please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce or a proof of concept, if possible.
- Any suggested fixes or mitigations.

## What to Expect

- We will acknowledge your report within a few business days.
- We will investigate and keep you informed of our progress.
- Once the issue is resolved, we will coordinate a disclosure timeline with
  you and credit you for the discovery if you wish.

Thank you for helping keep this project and its users safe!
