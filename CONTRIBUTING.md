# Contributing

Thanks for your interest in contributing! Contributions of all kinds are
welcome — bug reports, fixes, documentation improvements, and new ideas.

## Opening a Pull Request

1. **Fork and clone** the repository, then create a branch for your work:
   ```bash
   git checkout -b my-change
   ```
2. **Make your changes** and commit them with a clear, descriptive message:
   ```bash
   git commit -m "Describe what you changed and why"
   ```
3. **Push** your branch to your fork:
   ```bash
   git push origin my-change
   ```
4. **Open the pull request** against the `main` branch. In the description,
   explain what your change does and why, and link any related issues.
5. **Respond to review feedback.** A maintainer will review your PR — push
   follow-up commits to address any comments, and your branch will update
   automatically.

That's it — once your PR is approved, a maintainer will merge it. Thank you
for contributing!
